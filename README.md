## 📺 电视源 / 影视源（使用说明）

FreeBox 通过「数据源 / 接口地址」拉取影视内容，软件本身**不含任何资源**。下面仅说明**自用时的添加方式**，并预留你自己的源位置：

1. 打开 FreeBox → 设置 → 数据源（也称「接口」/「订阅源」）；
2. 粘贴一个**源地址**（接口或订阅链接），保存后刷新即可加载；
3. 也可按应用提示导入本地源文件。

> ⚠️ **合规与使用提醒**
> - 请**仅使用你有权使用的来源**（如已获授权的正版内容、公开/公共领域资源，或自建源）。
> - 本仓库为个人备份，**不内置、不分发任何第三方影视源**；请勿将未经授权的源公开传播，以免侵犯著作权。
> - 查找源的官方渠道：参阅原项目 Wiki 与社区 → <https://github.com/kknifer7/FreeBox>

- 说明：该源为 CatVodSpider 解析模块 + 内置 JSON 配置（含 43 个站点及 `custom_spider.jar`），需在 FreeBox 中加载 spider 后方可解析；**所聚合站点的内容授权由使用者自行负责**，本仓库不对其合规性背书。

### ⚠️ 安卓源在桌面端的限制（重要）

上例这类「安卓 TVBox 源」的 `spider` 指向的是 **安卓专用蜘蛛包**（本质上是 `classes.dex` 字节码，如 `custom_spider.jar`）。**桌面版 FreeBox 运行在 Java 虚拟机（JVM）上，无法加载 dex 格式的包**——dex 不是 Java 字节码，且依赖 `android.*` 类库，桌面端不存在。因此：

- 导入这类源**能成功**，但点播站点会**无法解析/播放**（直播部分可能仍可用）；
- 本仓库已对 FreeBox 源码做了改进：加载到安卓 dex 蜘蛛包时，会**弹出一次明确的中文提示**（说明根因与解决办法），而不是之前的泛化/重复弹窗；
- **想真正在桌面端用起来**，请用「电脑端专用源」（其 `spider` 指向 `.class` 格式的桌面 jar），或联系源作者获取桌面版蜘蛛包。

> 注：上述源码改动已合入本仓库 `main` 分支（仅改进提示与去重，不改变桌面源逻辑；安卓 dex 源本身仍不能在桌面播放，属架构性限制）。
